# Changelog

## Oct. 2026
- The footer, university resources have been updated. In the middle column under "Connect with Illinois" the link to Illinois Calendars was replaced with [Illinois Leads Strategic Plan](https://strategicplan.illinois.edu/).

## 2020
- Initial release. The first version of the header displayed a Block I beside the site name.
