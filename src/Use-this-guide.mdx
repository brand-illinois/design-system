# How to use this guide
This is a test system for the technical specifications of the brand requirements for the Illinois Header and Footer.
1. To make use of the visual measurement guides please select the 'Default' demo within the component you are testing.
2. Click on the ruler icon in the top menu bar to enable a spacing guide that displays the padding between elements.
3. Hover over each element to see a dynamic pop-up for sizing. This is similar to the experience in developer inspect tools.

Please see the controls menu at the bottom of this screen to change the elements and see the updated spacing.
